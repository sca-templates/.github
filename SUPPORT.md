# Support

## Where to get help

- **Questions and troubleshooting** — use
  [GitHub Discussions](https://github.com/orgs/sca-templates/discussions).
- **Bugs** — open an issue with the **Bug report** template in the affected
  repository.
- **Feature requests** — use that repository's **Feature request** template.
- **Security** — see [SECURITY.md](SECURITY.md); never a public issue.

## Expectations

This is a **maintainer-driven, best-effort** project with no SLA. Response
times depend on maintainer availability.
